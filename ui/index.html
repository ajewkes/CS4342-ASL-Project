Training setup

How big a step Adam takes on each update. Too high and the loss jumps around, too low and learning is slow. 0.001 is a safe start.
Images used for each update. Bigger batches are smoother and use more memory, smaller ones update more often.
How evenly the three training datasets are sampled. 0 gives each an equal share, 1 keeps their natural sizes, 0.5 is in between. The biggest dataset always leads.
How often the model is scored on the validation set. The best score so far is saved as model.pt. Checking more often gives a finer chart, but each check takes a few seconds.
How many parts the training data is split into. Each part is held out once while a fresh model trains on the rest. More folds give a steadier estimate but take longer.
Background processes that load images. More is faster once running but slower to start, about 5 seconds each on Windows. 0 loads in the main process.
